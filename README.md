# Pig Game

A simple two player dice game built with HTML, CSS, and JavaScript.

## About

Pig Game is a two player dice game where players take turns rolling a dice and try to reach the winning score first.

Rolling the dice adds the current dice value to the player's current score. However, rolling a 1 loses the current score and switches the turn to the other player.

Players can also hold their current score to add it to their total score and pass the turn.

## How to Play

1. Player 1 starts the game.
2. Click the Roll Dice button to roll the dice.
3. The dice value is added to the current score.
4. If you roll a 1, your current score is lost and the turn switches.
5. Click Hold to add your current score to your total score.
6. The first player to reach the winning score wins the game.
7. Click New Game to start a new game.

## Learning Goal

The main goal of this project is to practice JavaScript DOM manipulation, event handling, game logic, and managing application state by building an interactive two player dice game.
